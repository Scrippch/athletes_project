# Athletes Project

Django-приложение для импорта/экспорта данных о спортсменах в форматах JSON и XML.

## Возможности

- Ввод данных о спортсмене через HTML-форму с сохранением в файл (JSON или XML)
- Проверка вводимых данных (обязательные поля, диапазон возраста)
- Загрузка файлов .json / .xml на сервер с валидацией содержимого
- Невалидные файлы автоматически удаляются
- Имя файла генерируется на сервере (не используется имя от пользователя)
- Просмотр содержимого всех сохранённых файлов на сайте
- Сообщение, если на сервере ещё нет ни одного файла

## Технологии

- Python 3.13
- Django 6.1
- SQLite
- Хранение данных — файлы в `media/athletes_data/`

## Установка и запуск

git clone https://github.com/Scrippch/athletes_project.git
cd athletes_project

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

Открыть в браузере: http://127.0.0.1:8000/

## Страницы

- `/` — главная
- `/add/` — добавление спортсмена через форму
- `/upload/` — загрузка файла .json / .xml
- `/files/` — просмотр всех сохранённых файлов
